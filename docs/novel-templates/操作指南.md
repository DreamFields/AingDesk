# AingDesk 小说创作记忆系统 — 阶段一操作指南

> 利用 AingDesk 现有的**智能体 + 知识库**功能，零代码实现小说创作的情节记忆和多轮连续对话。

---

## 📋 总体思路

AingDesk 本身**没有跨会话记忆能力**，但我们可以利用：
- **知识库（RAG）** → 充当"长期记忆"，存储世界观、角色、已完成情节等
- **智能体（Agent）** → 充当"人格"，通过系统提示词让 AI 知道自己是小说创作助手，并主动查询知识库
- **对话内历史** → 充当"短期记忆"，AingDesk 会保留当前对话窗口的上下文（约50%模型上下文长度）

**流程图**：
```
你填写模板文档 → 导入知识库 → 创建智能体 → 新建对话（选智能体+勾选知识库）→ 开始创作
                                                                    ↓
                                              每写完一章 → 更新"已完成情节记录.md" → 重新导入知识库
```

---

## 🔧 第一步：创建知识库

### 1. 准备嵌入模型
- 打开 AingDesk，确保你已经安装了嵌入模型
- 推荐使用 **bge-m3:latest**（Ollama 默认嵌入模型）
- 如果使用第三方供应商，确保已配置嵌入模型

### 2. 创建知识库
1. 点击左侧菜单 **「知识库」**
2. 点击 **「创建知识库」**
3. 填写信息：
   - **知识库名称**: `我的小说` （或你的小说名字）
   - **描述**: `小说创作知识库，包含世界观、角色设定、故事大纲、已完成情节`
   - **嵌入模型**: 选择你已安装的嵌入模型
   - **检索策略**: 建议选 **混合检索**（向量+全文）
   - **最大召回数**: 建议设为 **8**（默认5可能不够）
   - **召回精度**: 保持默认 0.1
   - **分块大小**: 建议 **800**（比默认1000小一些，提高检索精度）
   - **重叠大小**: 建议 **150**

### 3. 填写模板文档
我在桌面 `AingDesk-Novel` 文件夹中准备了 5 个模板文件：

| 文件 | 用途 | 优先级 |
|------|------|--------|
| `01-世界观设定.md` | 描述故事的世界、时代、力量体系 | ⭐⭐⭐⭐ |
| `02-角色档案.md` | 所有重要角色的详细信息 | ⭐⭐⭐⭐⭐ |
| `03-故事大纲.md` | 剧情走向、伏笔、情感曲线 | ⭐⭐⭐⭐ |
| `04-已完成情节记录.md` | **最关键！** 每章写完后记录摘要 | ⭐⭐⭐⭐⭐ |
| `05-写作风格指南.md` | 文风、对话风格、禁忌 | ⭐⭐⭐ |

**请打开这些文件，将方括号 `[...]` 中的内容替换为你的小说实际设定。**

> 💡 不必一次全部填完。至少填写 **角色档案** 和 **故事大纲** 就可以开始。

### 4. 上传文档到知识库
1. 进入刚创建的知识库
2. 点击 **「上传文档」**
3. 选择你填写好的 `.md` 文件，全部上传
4. 等待文档解析完成（状态从"待解析"变为"已完成"）

## 🤖 第二步：创建智能体

### 1. 创建自定义智能体
1. 点击左侧菜单 **「智能体」**
2. 点击 **「创建智能体」**
3. 填写信息：
   - **名称**: `小说创作大师`
   - **头像**: 选一个你喜欢的 emoji（如 📝 或 ✍️）
   - **人物设定**（关键！复制下面的提示词）:

```
你是一位资深小说创作助手，专为长篇小说的连续创作而设计。

【核心职责】
1. 根据知识库中的世界观、角色设定和故事大纲来创作小说内容
2. 严格保持角色性格、说话方式、行为逻辑的一致性
3. 遵循故事大纲的走向，但可以在细节上发挥创意
4. 保持前后情节的连贯性，不制造矛盾

【创作规则】
- 每次创作前，先根据知识库回顾：当前写到哪里了？上一章发生了什么？主角现在是什么状态？
- 角色对话必须符合该角色在角色档案中定义的说话风格和性格特征
- 新引入的设定不能与知识库中已有的世界观设定矛盾
- 情节推进要参考故事大纲，不要偏离主线太远
- 注意伏笔的设置和呼应，知识库中有伏笔清单

【工作流程】
当用户要求你创作下一章/下一段时：
1. 先确认当前的创作进度和上下文
2. 如果信息不足，主动询问用户
3. 给出简要的创作计划（2-3句话概括本章要写什么）
4. 开始创作
5. 创作完成后，给出本章的情节摘要，提醒用户更新情节记录

【回答格式】
- 创作内容使用正文格式，不要加多余的标记
- 章节开头标注章节号和标题
- 遇到需要用户决策的分支点，暂停并询问用户的选择

【注意事项】
- 你的知识来源于知识库中上传的文档，那是这个故事的"圣经"
- 如果用户的要求与知识库设定矛盾，要提醒用户
- 你不是在重复知识库内容，而是基于这些设定来创造新的故事内容
```

4. 点击 **「确认」** 创建

## 💬 第三步：开始创作

### 1. 新建对话
1. 回到主页，点击 **「新建对话」**
2. 在新对话中，顶部选择你想用的大模型：
   - **推荐**: DeepSeek-V3 / Qwen 系列 / GPT-4o（上下文越长越好）
   - **本地 Ollama**: 推荐 qwen2.5:14b 或更大参数量的模型
3. 选择刚创建的智能体 **「小说创作大师」**

### 2. 绑定知识库
- 在对话界面，找到知识库选项（通常在输入框上方或设置中）
- **勾选**你创建的 `我的小说` 知识库

### 3. 开始对话创作
你可以这样开始：

> **第一次创作：**
> "请根据世界观和角色设定，创作第一章的开头。故事从[简述开场场景]开始。"

> **后续创作：**
> "请继续创作第二章，上一章[主角]已经[简述上章结尾]，接下来[简述本章走向]。"

> **调整和修改：**
> "这一段[角色名]的反应不太符合他的性格，他应该更[性格特征]一些，请重写这段对话。"

> **查看一致性：**
> "帮我检查一下，目前为止[角色名]的行为有没有和他的设定矛盾的地方？"

## 🔄 第四步：维护记忆（最关键！）

### 每次创作完一章后，执行以下步骤：

1. **让 AI 总结本章**
   > "请给出本章的情节摘要，包括：时间、地点、涉及角色、关键事件、角色状态变化、伏笔/线索。"

2. **更新情节记录文件**
   - 打开 `04-已完成情节记录.md`
   - 将 AI 给出的摘要按格式粘贴进去
   - 更新"当前进度"部分

3. **重新上传到知识库**
   - 进入知识库
   - 删除旧的 `04-已完成情节记录.md`
   - 重新上传更新后的文件
   - 等待重新解析完成

> ⚠️ **这一步是实现"记忆"的关键！** 不更新情节记录，AI 在下次对话中就不知道之前写了什么。

### 什么时候需要更新知识库？
| 情况 | 需要更新的文件 |
|------|--------------|
| 写完一章 | `04-已完成情节记录.md` |
| 新增/修改角色 | `02-角色档案.md` |
| 调整后续剧情走向 | `03-故事大纲.md` |
| 新增世界观设定 | `01-世界观设定.md` |
| 调整写作风格 | `05-写作风格指南.md` |

## 📝 最佳实践

### 1. 对话窗口管理
- **一个对话窗口 = 一个创作会话**（比如一章的创作）
- 对话太长后（超过20轮），建议新建对话继续，因为早期的对话历史会被截断
- 新建对话后，知识库仍然可用，不需要重复说明背景

### 2. 提高 RAG 检索质量
- 文档内使用清晰的标题层次（`#` `##` `###`）
- 角色名字在文档中出现时要一致（不要一会儿叫"李明"一会儿叫"小李"）
- 情节记录中多使用角色名和地点名，方便检索命中

### 3. 应对模型上下文限制
- Ollama 本地模型上下文通常较短（4K-8K），优先使用云端模型
- 如果发现 AI "忘记"了对话前期的内容，这是上下文窗口截断导致的，正常现象
- 关键信息应该放入知识库而非仅在对话中提及

### 4. 创作中的"记忆"技巧
- 每次开始新的创作对话时，先问：
  > "根据知识库，目前故事写到了哪里？主角的当前状态是什么？"
- 这样可以触发 RAG 检索，让 AI "回忆"起之前的情节
- 对话中途如果发现 AI 搞混了设定，直接提醒：
  > "根据设定，[角色名]的[某个属性]应该是[正确值]，请修正。"

## ⚡ 常见问题

**Q: AI 不记得上一章写了什么怎么办？**
A: 检查是否已更新 `04-已完成情节记录.md` 并重新上传到知识库。如果已更新，在对话开头主动询问"根据知识库，上一章发生了什么？"来触发检索。

**Q: AI 写出了和设定矛盾的内容怎么办？**
A: 直接指出矛盾并要求修正。同时检查知识库中的设定文档是否足够清晰详细。

**Q: 知识库更新后需要重建索引吗？**
A: 删除旧文档并重新上传会自动重建索引。如果修改不大，也可以使用"重新索引"功能。

**Q: 模型选择有什么建议？**
A: 
- 创意能力：DeepSeek-V3 > GPT-4o > Qwen-Max
- 长上下文：选择支持 32K+ 的模型
- 本地模型：至少 14B 参数，推荐 qwen2.5:14b

**Q: 可以同时进行多个小说项目吗？**
A: 可以！为每个小说创建独立的知识库，对话时勾选对应的知识库即可。
